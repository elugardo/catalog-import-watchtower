# Evidence

Screenshots, exports and short reports that back the rubric rows in `_docs/rubric.md`:
one folder per demonstration, named `<YYYY-MM-DD>-<what>/` (for example
`2026-11-20-real-llm-recovery/`), each with a `report.md` that says what was shown,
how to reproduce it, and which rubric row it serves. Never put CSV rows, vendor or
product names, tokens, or credentials here.
